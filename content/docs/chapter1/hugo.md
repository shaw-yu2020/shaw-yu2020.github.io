## **Book**主题配置

> 官方仓库：<https://github.com/alex-shpak/hugo-book>

作为子模块配置

```bash
git submodule add https://github.com/alex-shpak/hugo-book themes/hugo-book
```

作为子模块更新

```bash
git submodule init
git submodule update
```
